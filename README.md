
# Data Analytics – Module 1: Excel
## Excel Assignment 2 – Data Exploration and Data Cleaning

### 📌 Project Overview
This project focuses on exploring, cleaning, transforming, and preparing a Product Dataset using Microsoft Excel and Power Query.

As part of the Data Analytics Module 1 assignment, I performed data preprocessing techniques to identify and handle missing values, correct inconsistent data, remove duplicate records, restructure columns, and apply appropriate formatting.

The objective was to improve data quality, consistency, and readability to make the dataset suitable for further analysis.

### 📂 Dataset Description
**Dataset:** Product Dataset

**Columns:**
- Product ID
- Product Name
- Brand Name
- Quantity
- Category
- Price

### 🛠️ Tools & Techniques Used
- Microsoft Excel
- Power Query
- Find and Replace
- Remove Duplicates
- Text to Columns
- Merge Columns
- Median Calculation
- Conditional Formatting
- Currency and Date Formatting

### 🔍 Tasks Performed

#### 1. Handling Missing Values
- Identified missing values in the Price and Category columns.
- Used Power Query to identify products with missing category information.
- Analysed product names and assigned appropriate categories to missing records based on product type.
- Calculated the median price using the Group By operation in Power Query.
- Merged the calculated median price values with the original dataset.
- Replaced missing price values using the corresponding median values.

#### 2. Correcting Inconsistent Data
- Identified inconsistent text formats in the Product Name column.
- Used Find and Replace to standardize product names.
- Identified and corrected spelling mistakes and inconsistencies in the Category column.

#### 3. Removing Duplicates
- Checked the dataset for duplicate records based on all columns.
- Removed duplicate rows to maintain data accuracy and consistency.

#### 4. Splitting and Merging Columns
- Split the Product ID column into Manufacturing Date and Country Code.
- Removed unnecessary characters from the extracted values.
- Merged Brand Name and Product Name into a new column named Product Brand.

#### 5. Number and Date Formatting
- Formatted the Price column into currency format.
- Standardized the Manufacturing Date column to DD-MM-YYYY format.

#### 6. Conditional Formatting
- Applied Data Bars / Color Scales to the Price column to visualize price variations.
- Created a custom conditional formatting rule to highlight products belonging to the Electronics category.

### 📊 Key Learning Outcomes
Through this assignment, I gained practical experience in:

- Identifying and handling missing data.
- Using Power Query for data cleaning and transformation.
- Applying median imputation to handle missing numerical values.
- Standardizing inconsistent text and correcting data errors.
- Removing duplicate records.
- Splitting and merging columns for better data organization.
- Applying number formatting and conditional formatting.
- Preparing structured and reliable datasets for further analysis.

### 🎯 Project Outcome
Successfully cleaned and transformed the Product Dataset using Excel and Power Query. The final dataset is more consistent, structured, and ready for further data analysis.
